# Clip-Tool
Clip Tool will take locally or URL based youtube video and clip them in 1 minutes shorts based on ffmpeg.


Please make sure your dir is like following:

     static (dir)
     |---> style.css
     templates (dir)
     |---> index.html
     uploads (dir)
     |---> (program will automatically download video from internet and save in this folder before clipping)
     venv
     |---> (virtual enviroment as needed)
     app.py
     requirements.txt
